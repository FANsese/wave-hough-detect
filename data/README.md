# Data

## 1. Synthetic data for §3.1 (Figures 2–8) — included, no download needed

All data used in the simulation study is generated by the scripts in
[`../R/02_simulation/`](../R/02_simulation/):

```bash
Rscript ../R/02_simulation/generate_simulation_data.R
# -> stomach_simulation_data.csv   (x, y, ts, z)
```

Figures 3–8 are fully reproducible from this repository alone: the simulators are defined inside
the scripts that use them, and the random seed is derived deterministically from the simulation
parameters (see [`../docs/reproducibility-notes.md`](../docs/reproducibility-notes.md)).

## 2. Synthetic recording in the §3.2 input format — included

To make the real-data pipeline runnable without the experimental recording, this repository
includes a generator that writes a CSV in the **exact format** `tables2to4_pipeline.R` expects:

```bash
cd ../R/03_real_data
Rscript make_synthetic_recording.R
# -> synthetic_recording.csv   (90001 rows x 65 columns: time + Ch01 ... Ch64)
```

Then set line 23 of `tables2to4_pipeline.R` to `filename = "synthetic_recording.csv"` and run it.
The pipeline will extract spikes, separate them into wavefront planes, and print a circular-model
and a linear-model fit with R² for each plane — the same code path that produces Tables 2, 3 and 4.

The synthetic trace reproduces the structure of the real input: 64 electrodes numbered row-major
on an 8×8 grid, a time column in the same units, negative-going extracellular field potentials,
a slow baseline drift, and several propagating wavefronts originating outside the grid to the
south. It does **not** reproduce the published numbers, and it is not a substitute for the
experimental data.

## 3. The experimental recording — not included

The recording analysed in §3.2 of the paper is:

```
CM_PIN_Control_2N30_Aunor_2_input_60000.csv
```

extracellular field potentials from cultured Sprague-Dawley rat cardiac myocytes (embryonic day
16–19) on a 64-channel (8×8) planar gold MEA, recorded under control, normoxic conditions
(92.5–95.2 % dissolved O₂).

**It is not distributed here.** The recording was produced by a collaborating laboratory and the
authors of this repository do not hold the rights to redistribute it. This is the reason the
folder `Data_CK/` referenced at line 23 of `tables2to4_pipeline.R` is absent. The culture and
recording protocol is described in:

> Yeung, C.-K., Sommerhage, F., Wrobel, G., Law, J.K.-Y., Offenhäusser, A., Rudd, J.A.,
> Ingebrandt, S., Chan, M. *To establish a pharmacological experimental platform for the study of
> cardiac hypoxia using the microelectrode array.*
> J. Pharmacol. Toxicol. Methods **59**(3), 146–152 (2009).
> https://doi.org/10.1016/j.vascn.2009.02.005

Everything that can be reproduced from code alone is reproducible: the pipeline is deterministic
given its input, and the synthetic recording in section 2 exercises all of it. Only the numerical
values in Tables 2, 3 and 4 depend on the experimental file.

## 4. Gastric pilot data — not included

A separate 64-channel gastric slow-wave MEA recording, kindly provided by Prof. John A. Rudd,
motivated this line of work (see the Acknowledgment). It is a different preparation from the
cardiac recording analysed in §3.2 and its analysis code (spatial spike-distance histograms) is
not part of the method presented in the paper, so it is not included here.

## 5. Input format reference

For anyone substituting their own recording, `tables2to4_pipeline.R` expects:

| Requirement | Detail | Where it is used |
|---|---|---|
| Delimiter / header | comma-separated, with a header row | `read.csv`, line 24 |
| Column 1 | time stamps, numeric | `time = data[,1]`, line 30 |
| Columns 2…65 | one per electrode, numeric | `for (i in 2:ncol(data))`, line 37 |
| Column names | any name whose **3rd and 4th characters** are the electrode number, e.g. `Ch01` … `Ch64` | `f = function(str) as.integer(substr(str,3,4))`, line 27 |
| Electrode numbering | 1…64, row-major on the 8×8 grid | lines 82–88 |
| Signal polarity | negative-going spikes; detection uses `which.min` | line 90 |
| Sampling | 10 kHz is assumed by the millisecond axis in the trace plots | `xs = smooth$x/10`, `spike_activation_time.R:95` |

If your recording has a different number of channels, adjust `GRID_SIDE` in
`make_synthetic_recording.R` and the `40` in the plane-acceptance test at
`tables2to4_pipeline.R:322` (it is two thirds of the electrode count).
